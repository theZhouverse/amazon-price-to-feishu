# 交付验收入口

交付内容、排除项和验收标准统一见[SPEC第16.1节周一换周时点规则](SPEC.md#161-周一换周时点规则)及[SPEC第19～20节](SPEC.md#19-windows调度与验收)；部署只支持第14节定义的 Windows 宿主机本地路径。

实际完成情况和耗时见[TASKS](TASKS.md)，未解决风险见[REVIEWS](REVIEWS.md)。本文件只保留旧路径兼容，不将历史测试通过当作当前全流程已验收。

不交付 Docker 镜像、Compose 文件或容器迁移方案；交付的是 Windows 宿主机上的 `.venv`、配置模板、隐藏计划任务脚本、日志和运行数据保留规则。跨设备迁移必须按 SPEC 的本地宿主机步骤重新验收。
